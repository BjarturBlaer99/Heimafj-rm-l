## Changes in this milestone

- Savings bucket order and housing/goal inclusion use the website's metadata contract.
- Bucket contributions call the idempotent, atomic `add_savings_bucket_contribution` RPC; bucket history is visible and balance correction is separate.
- Amount fields add Icelandic separators; native date pickers replace typed dates on iOS/Android.
- Success feedback appears at the top within safe-area bounds.
- Transaction search/filtering works against the already-loaded month, avoiding a new database read per search change.
- Native sessions migrate from plaintext AsyncStorage into chunked SecureStore entries. Manifest-last writes preserve the prior session if an update is interrupted.
- Account tools offer a complete JSON data export, password recovery, support/privacy links and a reversible request for manual account deletion. Requests do not automatically notify the operator or delete the account.
